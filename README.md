# Product Recommendation System

An end-to-end product recommendation engine designed to enhance catalog data accuracy, standardize item classification, and deliver relevant product suggestions based on user interaction and item features.



## Key Highlights & Contributions

* **SQL Database Architecture:** Designed and maintained SQL database schemas for product catalogs, category structures, and user transaction logs.
* **Dataset Quality & Category Disambiguation:** Refined and standardized product descriptions to eliminate cross-category noise (e.g., ensuring distinct vector/keyword classification between "soft toys" and "toy trains"), directly improving recommendation accuracy.
* **Frontend Integration & Image Fallbacks:** Built responsive product card UI components with image rendering error-handling to maintain seamless visual presentation across catalog updates.



## Tech Stack

* **Database:** SQL (MySQL / PostgreSQL)
* **Backend:** Python / Node.js
* **Data Processing & ML:** Python (Pandas, Scikit-Learn)
* **Frontend:** React, HTML5, CSS3, JavaScript
